## 功能级（有最小可用实现，体验打折）

1. **文件移动/复制的长任务进度条**（FR-4.7 部分）——✅ **已补齐（0.4.3 / 第 61 轮）**
   - 原缺：fs/move 同步执行，无进度无取消；overwrite 在 schema 合法但无语义。
   - 补法（已实现）：tasks.start 异步任务化（kind 'move-copy'），状态栏全任务
     进度 + 按 taskId 精确取消；同盘 rename 瞬时、跨盘渐进复制→校验→删源
     （verify 全过才删源、取消绝不删源）；overwrite=先删目标旧内容（弹窗三选：
     覆盖/跳过/逐次询问）；单项失败不中止整批（部分成功标注）。
   - 回归锚点：fstask.test.ts 14 条（取消不删源/半成品清理/部分成功/HTTP 语义）。

2. **树节点右键菜单**（FR-2.10 的文件树部分）——✅ **已补齐（0.2.11）**
   - 0.2.3 落地 5 项（复制到/移动到/资源管理器/相对路径/绝对路径）；0.2.11 补上
     重命名（复用 RenameModal，目录 L3 确认链路不变）与删除（进回收站），
     并实装 F2/Delete 快捷键（此前快捷键帮助文案有承诺无实现）。
   - 本项从缺口清单闭合；右键菜单交互收敛见第 31 轮台账。

3. **打开时 7 天静默重分析**（FR-3.1 的 SHOULD 项）——✅ **已补齐（0.3.1）**
   - projectsRepo 新增 needsReanalyze 纯函数（analyzed_at 超 7 天；从未分析
     null 不触发——大项目全量分析必须显式），open 接口命中时 fire-and-forget
     后台重分析。本项从缺口清单闭合（第 36 轮 A1，测试 100 条锚点）。

4. **会话恢复的滚动位置**（FR-1.3 部分）——✅ **已补齐（0.3.8）**
   - 原缺：标签/页签/文件目标已恢复，滚动像素级位置未持久化。
   - 补法（已实现）：setActiveTabScroll 写回 + scrollJson 解析回放 + useTabScroll
     hook（滚动 300ms 防抖写会话、切标签/视图回放）。覆盖范围：工作台总览/卡片墙
     与项目概览页签；文件树与编辑器内部滚动粒度过细不持久化（有意范围）。

5. **自定义"我的视图"保存**（FR-4.11 部分）——✅ **已补齐（0.4.3 / 第 62 轮）**
   - 原缺：6 个内置视图可用，自定义筛选保存未做。
   - 补法（已实现）：settings 新键 custom_views_json（zod 校验 ≤30 条，不建
     新表）；侧栏「我的视图」分组 + CustomViewModal 七字段（类型/语言/技术栈/
     集合/标签/Git 状态/N 天没打开）；parseSubTab 增 view:custom:<id>；命令
     面板每视图一条命令；服务端过滤参数补 lang/stack/git/stale 1..3650。
   - 顺带修复真实缺陷：better-sqlite3 12.x 关闭 DQS，staleDays SQL
     datetime("now") 报错（内置 stale 视图必坏）→ 改单引号字面量。

6. **Git 单文件 diff 的分块懒加载**（FR-5.2 部分）——✅ **已补齐（0.4.3 / 第 63 轮）**
   - 原缺：大 diff 直接截断 200KB/500 行展示，无"查看完整"分页。
   - 补法（已实现）：服务端按行分页（offsetLines/limitLines ≤5000，响应增
     totalLines/offset/hasMore）；DiffView react-virtual 虚拟渲染 + GitTab
     useInfiniteQuery 页 500 行滚动续载，「已载 X/共 Y 行」如实提示；提交
     详情整段 patch 用法兼容（保持 200KB 截断现状）。

7. **拖拽添加项目**（FR-2.2 部分）——✅ **已放开（桌面版，2026-10-24 决策修订 / T-118）**
   - 原判定「按设计不做」的前提是「浏览器沙箱拿不到拖拽文件夹的绝对路径」——该前提
     仅在 Web 模式成立。经用户 2026-10-24 拍板：**桌面版放开拖拽登记**
     （preload 暴露 `webUtils.getPathForFile`，全局 drop → 添加弹窗预填，复用既有
     登记通道；服务端补「必须是文件夹」守卫）；**Web 模式维持不做**（沙箱限制，
     弹窗文案如实说明并指向三种可靠入口）。
   - 本条从缺口清单移除；任务总表 T-008 已同步备注。

8. **按标签过滤的项目视图**（0.2.11 新增缺口）——✅ **已补齐（0.3.1）**
   - ListFilters 加 tagId（子查询与 collectionId 同款）、GET /api/projects 收
     query.tag、GET /api/tags 附带 projectCount；侧栏「标签」分组点击开卡片墙
     （subTab=tag:<id>，parseSubTab 与 col: 同构）。本项闭合（第 36 轮 A2）。

9. **集合手动排序**（0.2.11 新增缺口）——✅ **已补齐（0.3.8）**
   - 原缺：sort_order 恒 0、无 PATCH 通道、前端无排序 UI，新集合恒垫底。
   - 补法（已实现）：POST /api/collections/reorder 按传入顺序单事务全量重排；
     侧栏集合右键菜单「上移/下移」（首末项禁用），与相邻集合交换后全量重排。

10. **GitHub Token 明文存储**（0.2.12 有意取舍，2026-10-08 入册）
    - 现状：settings.github_token 为 SQLite 明文，未用 Windows 凭据管理器（DPAPI）。
    - 为什么现在不做：本地单机单用户威胁模型下，能读 `%APPDATA%\ttFolio\` 的人
      已拥有同级别系统访问权，Token 明文不构成额外暴露面；引入 keytar/DPAPI
      增加原生依赖与打包复杂度，收益不成比例。
    - 补法（若仓库转公开或引入多用户）：凭据迁入系统凭据管理器，settings 只留
      「已配置」标记；届时需一次性迁移旧值。

## 明确不做（范围外，仅留扩展位——与 C-56..C-62 对应，不是缺口）

- Git push/pull/fetch/远程/凭据；多用户登录权限；目录自动扫描；架构图生成/调 AI；
  IDE 能力（编译/调试/语言服务/搜索替换/内嵌终端）；任务协作体系；云同步多端。
- 预留位已就位：owner_id/actor 字段、collections 成员与 {paths} 占位符、core/terminal/ 目录、
  core/scanner.ts 接口签名、settings 的 scan_root_dirs 字段。
- **界面国际化**（2026-10-08 入册）：界面中文硬编码是当前产品定位（个人工作台）
  的有意决策，README 已双语；未来若面向国际用户再引入 i18n 框架整体替换。

## 环境限制（非代码缺口）

- Playwright Chromium 首次运行需下载浏览器；下载失败时 verify 会将 e2e 记 SKIP 并说明（默认决策 8）。
- PowerShell 文件夹对话框弹窗可能被系统策略拦截；此时用"粘贴路径"入口（三种入口互为备份）。
- **e2e 为冻结资产**（2026-10-08 入册）：tests/e2e 三份 spec 因「不跑 e2e」的既定政策
  长期未运行，选择器已随三十余轮 UI 演进漂移，当前视为不可直接执行的冻结资产；
  解冻前置条件＝运行并修复选择器或按现状重写，建议安排在 1.0 之前的整备轮。
