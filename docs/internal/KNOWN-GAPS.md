## 功能级（有最小可用实现，体验打折）

1. **文件移动/复制的长任务进度条**（FR-4.7 部分）
   - 缺：前端进度 UI 与取消按钮未接到 fs/move 接口（接口层同步返回结果）。
   - 为什么：单文件/小目录移动在同盘 rename 下瞬时完成，进度价值低；跨盘大目录场景需要任务化改造。
   - 替代行为：移动/复制同步执行，完成或失败都有提示；跨盘走 复制+校验+删源，失败绝不删源。
   - 补法：把 fs/move 改为 tasks.start 异步任务（分析/索引已是该模式），前端状态栏进度条复用。

2. **树节点右键菜单**（FR-2.10 的文件树部分）——✅ **已补齐（0.2.11）**
   - 0.2.3 落地 5 项（复制到/移动到/资源管理器/相对路径/绝对路径）；0.2.11 补上
     重命名（复用 RenameModal，目录 L3 确认链路不变）与删除（进回收站），
     并实装 F2/Delete 快捷键（此前快捷键帮助文案有承诺无实现）。
   - 本项从缺口清单闭合；右键菜单交互收敛见第 31 轮台账。

3. **打开时 7 天静默重分析**（FR-3.1 的 SHOULD 项）
   - 缺：未做"打开项目时 analyzed_at 超 7 天自动重分析"。
   - 替代行为：卡片显示分析时间，项目页有显眼"重新分析"按钮；批量重分析在工具栏。
   - 补法：project/open 接口内判断 analyzed_at 触发 analyzeProjects（一行）。

4. **会话恢复的滚动位置**（FR-1.3 部分）
   - 缺：标签/页签/文件目标已恢复，滚动像素级位置未持久化（scrollJson 通道已留）。
   - 补法：前端把容器 scrollTop 写入 scrollJson，恢复时回放。

5. **自定义"我的视图"保存**（FR-4.11 部分）
   - 缺：6 个内置视图已实现；自定义筛选保存为视图未做（筛选参数本身可由 URL subTab JSON 承载）。
   - 补法：设置表存视图定义列表，侧栏渲染入口。

6. **Git 单文件 diff 的分块懒加载**（FR-5.2 部分）
   - 缺：大 diff 直接截断 200KB/500 行展示，无"查看完整"分页。
   - 替代行为：截断提示明确展示；完整 diff 可用任意 git 工具查看。
   - 注意：0.1.2 修的是**提交历史列表**的「加载更多」（keepPreviousData + 末尾判定），
     与本项的单文件 diff 分块是两回事，本项仍未做。

7. **拖拽添加项目**（FR-2.2 部分）
   - 缺：拖拽文件夹进窗口未实现（全局无 drop 监听；浏览器沙箱拿不到绝对路径，
     同名定位需要在已知根目录全盘搜索，误配风险高）。
   - 替代行为：添加项目弹窗的拖拽提示文案已于 0.2.11 修正为明示不可用，并引导
     三种可靠入口（粘贴路径 / 系统对话框 / 父目录批量登记）。

8. **按标签过滤的项目视图**（0.2.11 新增缺口：标签编辑器已上线，过滤视图未做）
   - 缺：/api/projects 的 ListFilters 无 tag 参数，侧栏/卡片墙无法按标签过滤。
   - 补法：ListFilters 加 tagId + WHERE EXISTS 子查询，侧栏标签区渲染入口。

9. **集合手动排序**（0.2.11 新增缺口：sort_order 列存在但恒 0、无 PATCH 通道）
   - 缺：collectionCreateSchema/PATCH 均不含 sort_order，前端无排序 UI；
     侧栏按 sort_order, created_at 排序，新集合恒在末尾。
   - 补法：PATCH schema 加 sort_order + 侧栏拖拽排序（或上下移按钮）。

## 明确不做（范围外，仅留扩展位——与 C-56..C-62 对应，不是缺口）

- Git push/pull/fetch/远程/凭据；多用户登录权限；目录自动扫描；架构图生成/调 AI；
  IDE 能力（编译/调试/语言服务/搜索替换/内嵌终端）；任务协作体系；云同步多端。
- 预留位已就位：owner_id/actor 字段、collections 成员与 {paths} 占位符、core/terminal/ 目录、
  core/scanner.ts 接口签名、settings 的 scan_root_dirs 字段。

## 环境限制（非代码缺口）

- Playwright Chromium 首次运行需下载浏览器；下载失败时 verify 会将 e2e 记 SKIP 并说明（默认决策 8）。
- PowerShell 文件夹对话框弹窗可能被系统策略拦截；此时用"粘贴路径"入口（三种入口互为备份）。
